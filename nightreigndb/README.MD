# ⚔️ Nightreign Database

A fan-made database for **Nightreign**, focused on helping players understand game mechanics, plan strategies, and make better decisions during their runs.

---

## 🌐 Live Website

👉 https://mmachida.github.io/nightreigndb/

---

## 📖 About

This project was created as a personal initiative while playing Nightreign.  
The goal is to provide a **clear, fast, and useful reference** for players who want deeper insight into the game.

The site is continuously updated as new information is discovered.

---

## 🚀 Features

### 🔍 Boss Database
- Organized boss information
- Easy navigation and lookup

### 🎯 Boss Prediction Tool
- Filter-based system
- Helps identify possible boss outcomes
- Dynamic probability calculation

### 🌑 Deep of Night Guide
Complete breakdown of the game mode, including:

- 📊 **Rating System**
  - Depth progression
  - Point calculations
  - Rank protection system

- 📈 **Difficulty Scaling**
  - Detailed scaling table
  - HP, Damage, Stance, and more

- ⚔️ **Deep Weapon Effects**
  - Positive effects
  - Curse effects
  - Clean card-based layout for readability

- 🔮 **Deep Relic Effects**
  - Full list of relic modifiers
  - Positive and Curse separation
  - Easy-to-scan UI

---

## 📌 Project Goals

- Provide **accurate and accessible information**
- Keep the interface **clean and fast**
- Help players **optimize their runs**
- Continuously improve with new discoveries
